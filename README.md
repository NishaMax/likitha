# Likitha

Likitha is a mobile-first Sinhala story and novel publishing platform for Sri Lanka.

## Local development

Requirements:

- Node.js 22+
- npm

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Local configuration is read from `.env`. Use `.env.example` as the template. The current homepage is a static design foundation; database, authentication, and publishing services will be added in later phases.

## Validation

```bash
npm run lint
npm run build
```
